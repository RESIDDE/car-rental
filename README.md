# Car Rental Desk

Fleet, trips, drivers, costs and reports for a car rental business, with a spinnable 3D car.

```
npm install
npm run dev      # local dev server
npm run build    # production build in dist/
```

Data is saved in the browser (localStorage).

3D car model: "Ferrari 458 Italia" by vicent091036 (CC BY 4.0), from the three.js examples.
